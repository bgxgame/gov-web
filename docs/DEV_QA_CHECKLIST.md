# 前端开发与提测检查清单

## 1. 开发前
- 确认 Node 与依赖已安装：`npm install`
- 确认 `.env` 中接口地址、超时、日志阈值配置正确
- 确认文件编码为 UTF-8 无 BOM
- 确认后端服务、数据库、对象存储等依赖可用

## 2. 开发中
- 页面提示文案统一为中文，避免英文或模糊提示
- 新增请求统一走 `src/utils/request.js`
- 新增环境变量统一补到 `src/config/app-config.js` 与 `.env.example`
- 涉及权限的页面同时验证管理员、部门负责人、普通用户三类角色
- 涉及慢请求、路由卡顿问题时，先记录 `traceId` 再联查后端日志

## 3. 提交前必做
- 单元测试：`npm run test`
- 关键烟雾巡检：`npm run test:smoke`
- 端到端测试：`npm run test:e2e`
- 生产构建：`npm run build`
- 构建体积分析：`npm run build:stats`
- 运行 Playwright 前确认本机 `Chrome` 可用；如需改用其他浏览器通道，设置 `PLAYWRIGHT_BROWSER_CHANNEL`

## 4. 人工回归重点
- 登录、退出、账号停用提示
- 左侧菜单显示与点击跳转
- 项目新增、编辑、删除、提交审批
- 审批待办、驳回、通过后的状态变化
- 用户、部门、角色、菜单权限设置
- 首页地图加载、下钻、返回上级、项目详情弹窗
- 地图资源新增后，验证 `resource-manifest.json` 或文件命名是否生效

## 5. 发布前观察项
- `logs/` 中开发或构建日志是否异常膨胀
- 构建产物是否出现明显体积回升
- 路由慢日志、慢请求日志是否集中出现在某一条链路
- 后端 `perf.log` 与 `audit.log` 是否能按 `traceId` 串联

## 6. 缺陷记录建议
- 问题现象
- 触发角色
- 触发菜单路径
- 发生时间
- `traceId`
- 前端控制台错误
- 后端对应日志位置
